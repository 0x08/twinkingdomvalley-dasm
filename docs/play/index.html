Twin Kingdom Valley

Trevor Hall's 1983 BBC Micro adventure: the original game, running in your browser.

Choose an option with a number key, then type commands such as N, TAKE LAMP, LOOK, INVENTORY or HELP and press Return. Press TAB (or the button) at the ? prompt to see a picture. *SAVE and *LOAD keep one saved game in this browser.

This is the game's own 6502 code in an emulator with a small stand-in for the BBC's operating system, from the disassembly project. See also every picture.
